# Hippo Boost — Política de Privacidade

Página pública e independente da política do aplicativo Android Hippo Boost (`com.plushdrop.mergefofo`). Contato do responsável: vini.livept2@gmail.com.

Este repositório contém apenas a política, o gerador da página estática e as imagens de identidade já autorizadas. Não contém código do jogo, APK/AAB, chave de assinatura ou senhas. Não modifica a página antiga do Plush Drop.

O documento-fonte é `privacy.md`. `index.html` contém o texto completo e pode ser lido sem JavaScript ou cadastro. A hospedagem usa GitHub Pages na branch `main`, pasta raiz. `.nojekyll` mantém o HTML estático sem processamento pelo Jekyll.

Para atualizar, edite `privacy.md`, ajuste a data do documento e do gerador e execute `python3 build_page.py`. O gerador requer o pacote Python Markdown. Após o GitHub informar o endereço da página, registre-o em `site-url.txt` para incluir metadados canônicos e sitemap.
